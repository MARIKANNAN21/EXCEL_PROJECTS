# 📊 IT Staffing Recruitment MIS Dashboard (Jan – Jun 2025)

## 🔍 Project Overview

This project is an **Excel-based MIS Dashboard** designed to analyze and track recruitment performance for an IT staffing team.

It provides insights into:

* Hiring pipeline
* Recruiter performance
* Sourcing effectiveness
* Salary trends
* Monthly hiring performance

---

## 🎯 Key Metrics

* **Total Requisitions:** 50
* **Total Placements (Joined):** 27
* **Conversion Rate:** 54%
* **Average Turnaround Time (TAT):** 18.59 days
* **Average Offered CTC:** 8.65 LPA

---

## 📈 Dashboard Features

### 1️⃣ Sourcing Channel Analysis

* Compares candidates sourced vs joined
* Channels:

  * LinkedIn
  * Naukri
  * Referral
  * Walk-in

📌 Insight: LinkedIn is the highest sourcing channel but has a drop in conversion.

---

### 2️⃣ Monthly Hiring Trend

* Tracks hiring performance from Jan to Jun 2025
* Shows:

  * Total sourced candidates
  * Total joined candidates

📌 Insight: Stable sourcing but fluctuating join rates.

---

### 3️⃣ Hiring Funnel

Stages:

* Total Requisitions
* Interviews Conducted
* Selected Candidates
* Offers Accepted
* Candidates Joined

📌 Insight: Major drop observed after interview stage.

---

### 4️⃣ Recruiter Performance

Evaluates individual recruiters based on:

* Total requisitions handled
* Placements (joins)
* Average TAT

📌 Insight: Senthil Kumar handled the highest number of requisitions with strong performance.

---

### 5️⃣ Salary Analysis

* Compares:

  * Expected CTC
  * Offered CTC
  * Gap Analysis

Roles covered:

* Data Analyst
* MIS Analyst
* Business Analyst
* Data Engineer
* Data Scientist
* Reporting Analyst

📌 Insight: Data Engineer roles show a noticeable positive gap in salary expectations.
